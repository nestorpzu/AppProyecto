1. Objetivos

1.1 Objetivo General

La aplicación Prototipo App se ha diseñado como una herramienta de gestión integral para la organización y seguimiento de datos relacionados con partidas de League of Legends. Se pretende ofrecer una interfaz intuitiva que permita al usuario administrar de forma eficiente la información de jugadores, campeones y partidas, así como generar informes y realizar operaciones de importación y exportación de datos.

1.2 Objetivos Específicos

  • Centralizar el registro y la gestión de jugadores, incluyendo datos personales, posición y nacionalidad.
  • Mantener un catálogo actualizado de campeones con su rol, dificultad e imagen asociada.
  • Registrar partidas vinculando jugadores y campeones, almacenando fecha, resultado y estadísticas KDA.
  • Facilitar la búsqueda y filtrado avanzado de registros en cada una de las tres entidades.
  • Generar informes en formato PDF mediante JasperReports, tanto de campeones como de partidas filtradas por resultado.
  • Permitir la importación y exportación de datos en formatos CSV y JSON para garantizar la interoperabilidad con otros sistemas.
  • Garantizar la validación de los datos introducidos por el usuario, minimizando errores y asegurando la coherencia de la información almacenada.

1.3 Público Objetivo

Este manual va dirigido a cualquier usuario de la aplicación Prototipo App, sin necesidad de conocimientos técnicos previos. Se asume que el usuario dispone de un equipo con el sistema operativo Windows o Linux y que cuenta con acceso a una base de datos MySQL configurada correctamente.

2.1 Descripción de la Aplicación

Prototipo App es una aplicación de escritorio desarrollada en JavaFX que permite gestionar tres entidades principales interrelacionadas: Jugadores, Campeones y Partidas. La interfaz se organiza en tres pestañas dentro de una ventana única, cada una dedicada a una entidad.

La persistencia de datos se realiza mediante una base de datos MySQL (esquema app_prototipo), con las tablas jugadores, campeones y juegan (esta última actúa como tabla intermedia que relaciona jugadores y campeones con la información de la partida).

3. Funcionamiento

3.0 Vista General de la Interfaz

Al iniciar la aplicación, se muestra la ventana principal compuesta por tres pestañas: Jugadores, Campeones y Partidas. Cada pestaña contiene una tabla con los registros de la entidad correspondiente, así como botones de acción en la parte superior.

La estructura común de cada pestaña incluye:

  • Título de la entidad (p. ej., «Lista de Jugadores»).
  • Botón «Añadir» para crear nuevos registros.
  • Botón «Lista de filtros» para abrir el diálogo de filtrado avanzado.
  • Botón «Borrar filtros» para restablecer la tabla a su estado original.
  • Campo de búsqueda con icono de lupa para filtrado rápido por nombre.
  • Menú «Importar/Exportar» con opciones de CSV y JSON.
  • Tabla con columnas específicas de cada entidad y una columna de acciones (editar/eliminar).
Nota: Se puede acceder a este manual en cualquier momento pulsando la tecla F1 desde la ventana principal de la aplicación.

3.1 Jugadores

3.1.1 Vista Principal y Búsqueda

La pestaña Jugadores muestra una tabla con todos los jugadores registrados. Las columnas visibles son:

Columna Descripción Ejemplo
NOMBRENombre completo del jugadorFaker
DESCRIPCIÓNDescripción breve del jugadorMid laner profesional
EDADEdad del jugador (entre 18 y 99)27
EMAILCorreo electrónico del jugadorfaker@lol.com
NACIONALIDADPaís de origenCorea del Sur
POSICIÓNPosición en el juegoMid
ACCIONESBotones de editar y eliminar—

Se puede realizar una búsqueda rápida escribiendo en el campo de texto junto al icono de lupa. La tabla se filtra de forma automática mientras se escribe, mostrando únicamente los jugadores cuyo nombre contiene el texto introducido.

3.1.2 Añadir Jugador

Para añadir un nuevo jugador se siguen los siguientes pasos:

Se hace click en el botón «Añadir Jugador» situado en la parte superior derecha de la pestaña Jugadores.
Se rellena el formulario modal con los datos del jugador:
CampoObligatorioValidación
NombreSíSolo letras y espacios
DescripciónSíTexto libre
EdadSíNúmero entero entre 18 y 99
EmailSíFormato de correo electrónico válido
NacionalidadSíSolo letras y espacios
PosiciónSíValores posibles: Top, Jungla, Mid, ADC, Soporte
Se comprueba que los campos muestran un borde verde (válido) y no rojo (error de validación).
Se pulsa el botón «Guardar» para confirmar. Si la validación falla, se muestra un mensaje de error y no se procede al guardado.
Si los datos son correctos, el jugador se añade a la tabla y se muestra un mensaje de confirmación.

3.1.3 Editar Jugador

Para modificar los datos de un jugador existente:

Se localiza el jugador en la tabla y se hace click en el botón de editar (icono de lápiz) en la columna ACCIONES.
Se abre un diálogo modal con los datos actuales del jugador precargados en los campos del formulario.
Se modifican los campos deseados. Los campos se validan en tiempo real con borde verde (válido) o rojo (incorrecto).
Se pulsa «Guardar» para confirmar los cambios. Los datos se actualizan en la base de datos y la tabla se refresca automáticamente.

3.1.4 Eliminar Jugador

Para eliminar un jugador del sistema:

Se hace click en el botón de eliminar (icono de papelera) en la columna ACCIONES de la fila correspondiente.
Se muestra un diálogo de confirmación para evitar eliminaciones accidentales.
Si se confirma la eliminación, se eliminan también todas las partidas asociadas a dicho jugador (eliminación en cascada).
Atención: Al eliminar un jugador, se borran automáticamente todas las partidas en las que participa. Esta acción es irreversible.

3.1.5 Filtros Avanzados de Jugadores

El sistema de filtros avanzados permite buscar jugadores cumpliendo múltiples criterios simultáneamente:

Se hace click en el botón «Lista de filtros».
Se abre un diálogo modal donde se pueden rellenar los campos por los que se desea filtrar: nombre, descripción, email, nacionalidad, posición y edad.
Se dejan en blanco los campos que no se deseen utilizar como criterio de filtrado.
Se pulsa «Aplicar filtros» y la tabla se actualiza mostrando solo los registros que cumplen todos los criterios indicados.
Para eliminar los filtros y volver a mostrar todos los registros, se pulsa el botón «Borrar filtros».

3.2 Campeones

3.2.1 Vista Principal y Búsqueda

La pestaña Campeones presenta la tabla de campeones con las siguientes columnas:

Columna Descripción Ejemplo
NOMBRENombre del campeonAhri
DESCRIPCIÓNDescripción del campeonLa zorra de nueve colas
IMAGENImagen del campeon cargada desde la API—
ROLRol principal del campeonMago

ACCIONESBotones de editar y eliminar—

La búsqueda rápida funciona de forma idéntica a la de jugadores: se escribe en el campo de búsqueda y la tabla se filtra automáticamente por nombre de campeon.

Nota: Las imágenes de los campeones se cargan desde internet (API de Riot Games). Si no hay conexión a internet, las imágenes no se mostrarán.

3.2.2 Añadir Campeon

Para añadir un nuevo campeon al catálogo:

Se hace click en el botón «Añadir Campeon».
Se rellena el formulario modal con los datos del campeon:
CampoObligatorioValidación
NombreSíSolo letras y espacios
DescripciónSíTexto libre
RolSíValores posibles: Asesino, Tanque, Mago, Tirador, Luchador, Soporte
DificultadSíValores posibles: Baja, Media, Alta
Se pulsa «Guardar». Si el nombre coincide con un campeon existente en la API de Riot, se carga automáticamente su imagen.

3.2.3 Editar Campeon

El proceso de edición de un campeon es análogo al de un jugador:

Se hace click en el botón de editar (icono de lápiz) en la columna ACCIONES.
Se modifican los campos deseados en el diálogo modal.
Se pulsa «Guardar» para confirmar los cambios.

3.2.4 Eliminar Campeon

Al eliminar un campeon, se sigue el mismo procedimiento que con un jugador. Se hace click en el botón de eliminar (icono de papelera) y se confirma la acción en el diálogo de confirmación.

Atención: Al eliminar un campeon, se eliminan en cascada todas las partidas en las que participa dicho campeon. Esta acción es irreversible.

3.2.5 Filtros Avanzados de Campeones

Se accede al diálogo de filtros avanzados pulsando «Lista de filtros». Se pueden filtrar los campeones por nombre, descripción, rol y dificultad. Los campos vacíos se ignoran en el filtrado. Para restablecer la vista completa, se pulsa «Borrar filtros».

3.3 Partidas

3.3.1 Vista Principal y Búsqueda

La pestaña Partidas muestra la tabla de partidas registradas con las columnas:

Columna Descripción Ejemplo
JUGADORESNombre del jugador que participóFaker
CAMPEONESNombre del campeon utilizadoAhri
FECHAFecha de la partida15/05/2026
KDARelación Kills/Deaths/Assists5/2/8
RESULTADOResultado de la partidaVictoria
ACCIONESBotones de editar y eliminar—

La búsqueda rápida permite filtrar partidas por nombre de jugador o nombre de campeon.

3.3.2 Añadir Partida

Para registrar una nueva partida:

Se hace click en el botón «Añadir Partida».
Se rellena el formulario modal con los datos de la partida:
CampoObligatorioValidación
JugadorSíAutocompletado con nombres existentes. Se selecciona uno de la lista.
CampeonSíAutocompletado con nombres existentes. Se selecciona uno de la lista.
FechaSíSelector de fecha. No puede ser futura.
KDASíFormato x/y/z (kill/death/assist, números enteros no negativos)
ResultadoSíValores posibles: Victoria, Derrota, Empate
Se pulsa «Guardar». La partida se registra en la base de datos y aparece en la tabla.
Autocompletado: Los campos Jugador y Campeón disponen de autocompletado inteligente. Al escribir, se muestran sugerencias con los nombres de jugadores y campeones existentes en la base de datos. Es obligatorio seleccionar un valor de la lista desplegable; no se pueden introducir nombres que no estén registrados.

3.3.3 Editar Partida

Para editar una partida existente se hace click en el botón de editar (icono de lápiz). Se abre un diálogo modal donde se pueden modificar los siguientes campos:

  • Fecha
  • KDA
  • Resultado
Nota: Los campos Jugador y Campeón no son editables una vez creada la partida, ya que constituyen la identidad de la misma. Si se necesita cambiar el jugador o campeon, se debe eliminar la partida y crear una nueva.

3.3.4 Eliminar Partida

Se hace click en el botón de eliminar (icono de papelera) y se confirma la acción. La partida se elimina únicamente de la tabla juegan, sin afectar al jugador ni al campeon asociados.

3.3.5 Filtros Avanzados de Partidas

Se pulsa «Lista de filtros» para abrir el diálogo de filtros. Se pueden filtrar las partidas por: jugador, campeon, fecha, KDA y resultado. Al igual que en las demás entidades, los campos vacíos se ignoran. Se pulsa «Borrar filtros» para restablecer la tabla.

3.4 Informes

La aplicación permite generar informes en formato PDF mediante JasperReports. Se dispone de dos tipos de informes:

3.4.1 Informe de Campeones

Se accede a la pestaña Campeones.
Se hace click en el botón «Informes» situado en la parte superior.
Se genera automáticamente un informe PDF con la lista completa de campeones, incluyendo nombre, descripción, rol, dificultad e imagen. Además, se incluye un gráfico de barras con la distribución de campeones por rol.
El informe se abre en el visor de PDF predeterminado del sistema.

3.4.2 Informe de Partidas

Se accede a la pestaña Partidas.
Se hace click en el botón «Informes».
Se muestra un diálogo donde se selecciona el filtro de resultado:
OpciónDescripción
VictoriaSe incluyen únicamente las partidas ganadas.
DerrotaSe incluyen únicamente las partidas perdidas.
EmpateSe incluyen únicamente las partidas empatadas.
TodosSe incluyen todas las partidas sin filtrar por resultado.
Se genera el informe PDF con las partidas filtradas según la opción seleccionada.

3.5 Importar / Exportar Datos

Cada pestaña dispone de un menú desplegable «Importar/Exportar» con las siguientes opciones:

3.5.1 Exportar a CSV

Se despliega el menú «Importar/Exportar» y se selecciona «Exportar CSV».
Se abre un diálogo de selección de archivo donde se elige la ubicación y el nombre del archivo CSV.
Los datos de la tabla actual (incluyendo los filtros aplicados) se exportan al archivo CSV con las cabeceras correspondientes.

3.5.2 Exportar a JSON

Se selecciona «Exportar JSON» del menú desplegable.
Se elige la ubicación y el nombre del archivo JSON.
Los datos se exportan en formato JSON estructurado, manteniendo la jerarquía de los campos.

3.5.3 Importar desde CSV

Se selecciona «Importar CSV» del menú desplegable.
Se elige el archivo CSV a importar mediante el diálogo de selección de archivo.
Se leen los datos del archivo CSV. Si un registro ya existe (mismo ID), se actualiza; si no existe, se inserta como nuevo.
Al finalizar, se muestra un resumen con los registros insertados y actualizados.
En partidas: Si al importar una partida el jugador o campeon referenciado no existe en la base de datos, se crean automáticamente registros nuevos para ambos con los datos mínimos necesarios.

3.5.4 Importar desde JSON

El proceso es idéntico al de importación CSV, pero seleccionando la opción «Importar JSON». Se elige el archivo JSON, se procesa y se insertan o actualizan los registros según corresponda.

4. Solución de Problemas

A continuación se describen los problemas más comunes que pueden surgir durante el uso de la aplicación, junto con sus causas probables y las soluciones correspondientes.

4.1 Error de Conexión con la Base de Datos

Síntoma: Al iniciar la aplicación, no se cargan datos en las tablas y se muestra un mensaje de error de conexión.
Causa posibleSolución
El servidor MySQL no está ejecutándose Se inicia el servicio MySQL. En Windows: net start mysql. En Linux: sudo systemctl start mysql
Credenciales incorrectas Se comprueba que el usuario y contraseña en la configuración de la base de datos (root/root por defecto) coinciden con los de la instalación de MySQL.
La base de datos app_prototipo no existe Se ejecuta el script SQL de creación de la base de datos proporcionado con la aplicación.
El puerto 3306 está ocupado Se verifica que no hay otro servicio usando el puerto 3306. Si MySQL está en otro puerto, se ajusta la URL de conexión.

4.2 Errores de Validación

Síntoma: Los campos del formulario muestran borde rojo y no se permite guardar el registro.
CampoErrorSolución
Nombre / NacionalidadContiene números o caracteres especialesSe introduce únicamente letras y espacios
EmailFormato no válidoSe utiliza el formato usuario@dominio.com
EdadFuera del rango permitidoSe introduce un valor entre 18 y 99
KDAFormato incorrectoSe utiliza el formato x/y/z con números enteros no negativos (ej.: 5/2/8)
Campo obligatorioCampo vacíoSe rellena el campo obligatorio

4.3 Problemas de Importación / Exportación

Síntoma: La importación falla o los datos importados no se muestran correctamente.
ProblemaCausaSolución
Error al importar CSV El archivo no tiene el formato esperado o las cabeceras no coinciden Se comprueba que el archivo CSV tiene las cabeceras correctas y los datos están separados por comas. Se puede usar un archivo exportado previamente como referencia.
Error al importar JSON El archivo JSON no tiene la estructura esperada Se verifica que el archivo JSON respeta la estructura generada por la exportación de la aplicación.
Los datos importados no aparecen La importación se realizó con filtros activos en la tabla Se borran los filtros de búsqueda para mostrar todos los registros.
Error de codificación en CSV El archivo CSV no está en UTF-8 Se guarda el archivo CSV con codificación UTF-8 para evitar problemas con caracteres especiales.

4.4 Problemas con Informes JasperReports

Síntoma: El informe no se genera o se muestra un error al intentar crear el PDF.
Causa posibleSolución
No hay datos en la tabla seleccionada Se añaden registros a la entidad correspondiente antes de generar el informe.
Las imágenes de campeones no se cargan en el informe Se verifica la conexión a internet, ya que las imágenes se obtienen desde la API de Riot Games.
Error de Java al generar el PDF Se comprueba que los archivos .jasper están en el classpath de la aplicación.

4.5 Problemas Generales

ProblemaSolución
La aplicación no arranca Se verifica que Java 21 esté instalado y configurado correctamente ejecutando java -version en un terminal.
La ventana se ve mal o los estilos no se aplican Se comprueba que los archivos CSS se encuentran en el directorio de recursos y que el archivo estiloMain.css se carga correctamente.
Las imágenes de campeones no se muestran en la tabla Se verifica la conexión a internet. Las imágenes se cargan desde la URL de Riot Games (ddragon.leagueoflegends.com).
La búsqueda no funciona Se asegura de que no hay filtros avanzados activos que puedan estar restringiendo los resultados. Se pulsa «Borrar filtros» para restablecer la tabla.
La pantalla de ayuda no se abre con F1 Se comprueba que la ventana principal de la aplicación tenga el foco. Se hace click en la ventana y se pulsa F1 de nuevo.
Consejo: Si el problema persiste tras aplicar las soluciones indicadas, se recomienda reiniciar la aplicación. Si el error continúa, se verifica que la base de datos MySQL esté accesible y que los datos de conexión son correctos.
